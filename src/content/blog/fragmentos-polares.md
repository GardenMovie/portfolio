Meu primeiro projeto no InterAntar é o jogo Fragmentos Polares. O jogo é um point-and-click educativo que ajuda os jogadores a aprender características físicas do Ártico e da Antártica, assim como sobre os animais que vivem nessas regiões.

Eu fui o principal desenvolvedor do projeto, criando scripts, UIs e integrando assets produzidos pela equipe.

**Habilidades aplicadas**

- Unity 2D
- C#
- Programação orientada a objetos (POO)
- Versionamento de código com Git

**Aprendizados**

- Aprendi a organizar um projeto Unity e usar prefabs para facilitar o desenvolvimento
- Melhorei meu entendimento de design patterns em C#
- Melhorei meu entendimento de âncoras e seus usos em designs responsivos de UI
