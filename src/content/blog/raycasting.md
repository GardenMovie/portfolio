Durante o primeiro quadrimestre de 2025 cursei a disciplina Práticas de Engenharia de Software na Universidade Federal do ABC (UFABC), trabalhei em um projeto em grupo que combina técnicas clássicas de renderização 3D com tecnologias web modernas.

Dê uma olhada no GitHub ou no site.

<https://lnkd.in/d2VbgtNV>

<https://lnkd.in/dd56HEiq>

**O que foi desenvolvido**

- Motor de renderização 3D baseado em raycasting (gera níveis 3D a partir de mapas 2D).
- Implementação de movimento do jogador, detecção de colisão e lógica de inimigos.
- Arquitetura modular seguindo princípios de engenharia de software (TypeScript, MVC, testes unitários).
- Interface web com React e Shadcn UI para jogar e criar níveis.

**Habilidades aplicadas**

- TypeScript
- React / ShadcnUI
- Diagramas UML
- Práticas ágeis
- Testes unitários
- Versionamento com Git

Esse projeto foi uma ótima oportunidade para aprender mais sobre React, TypeScript e engenharia de software aplicada. Espcialmente o uso de práticas ágeis e de testes unitários facilitou muito o desenvolvimento do projeto garantindo que o código fosse mais confiável, modular e fácil de evoluir.
