Meu segundo projeto no InterAntar é o Polaroo. Ele foi inspirado no jogo Termo (ou Wordle), só que as palavras são referentes as regiões polares.

Eu fui o principal desenvolvedor do projeto, criando scripts, UIs e integrando assets produzidos pela equipe.

**Habilidades aplicadas**

- Unity 2D
- C#
- Programação orientada a objetos (POO)
- Noções de UI/UX
- Versionamento de código com Git

**Aprendizados**

- Fortaleci minhas habilidades em pensamento algorítmico e lógica de programação enquanto desenvolvia a lógica do puzzle
- Melhorei meu entendimento em transições de cenas para melhorar a UX
- Desenvolvi meu entendimento sobre o tratamento em tempo real do input do jogador
- Ganhei experiência com a publicação de jogos na Google Play Store
